**范围：** 以 `ascend-baseline`（`e152aeb`）为起点，核对用户任务、已有 Ascend 交付记录及代码组织。本批工作限于制定窗口计划。

**验证：** 按基线 Git 树统计 `src/` 下 232 个 Python、C/C++ 源文件，核对 `SourceAcquisition` 的部署依赖、`SGLangObservation` 创建平台标记器和 `FittedCosts` 使用框架样本复用规则。检查七个阶段各有交付条件、状态与基线相符、本机交付记录可读且尝试数相符。本批未运行构建、采集或仿真。

**验证**　公共 C++ 库及两个程序在 modeling 镜像完成 Release 构建；重建原生取证与无设备控制镜像。两种部署映射和五种无效部署符合原合同。同一批真实样本重拟合的 973 项模型与基线一致，独立检查了角色复用和跨设备拒用。以新镜像首次得到的 TP1 粗图运行基线与新二进制，模板、工作身份、固定图成本三份输出分别逐项相等。[部署检查](../../../data/architecture-acquisition-performance/r1/deployment-check.json) · [图对照](../../../data/architecture-acquisition-performance/r1/graph-baseline.json) · [拟合对照](../../../data/architecture-acquisition-performance/r1/fitting-baseline.json)

**结论与限制**　R1.2、R1.3、R1.4 的三条职责链均已实改，R1.7 的两种拓扑各三路结论在阶段收尾记录。单卡后续需要跨过两个具体边界：SGLang 的 `ModelRunner.init_torch_distributed` 在权重构造前创建真实进程组，`WorkerRolePlan` 在选择代表前向组中所有 rank 收集事实。Qwen3 的本地 query/KV head 数由 attention TP 组大小决定，只限制设备可见性无法产生 TP2 分片。

## 2026-11-21 — R1.6 复审留出请求与训练来源

**范围**　沿请求抽样、来源资格检查、实际库选择及三条评价路径复审验证边界。

**改动**　旧矩阵在发布目标请求前装配训练模板，还会把留出请求作为空训练集的来源。现在按声明和种子独立发布目标，训练使用显式探针或已有库。已发布集合与预测共用同一处主库和局部库选择规则，验证只对该目标用到的库判定资格，来源缺失可追溯到原生任务的停止原因。

**验证**　用真实 TP1 训练声明及 TP2 来源声明构造缺库和不相关来源失败的离线条件。缺训练库时仍能生成同一批留出请求，空训练集会停止，显式训练输入保持原样。所属库有缺项时报告原原因，其他域的失败保留在总表。[抽样隔离](../../../data/architecture-acquisition-performance/r1/matrix-draw-isolation.json) · [来源选择](../../../data/architecture-acquisition-performance/r1/matrix-source-selection.json)

**结论与限制**　两项缺陷都来自实验编排跨过训练与目标的边界。本批复用既有观测，未增加原生尝试。

## 2026-11-21 — R1 交付与完整模式三路对照

**范围**　从 `e152aeb` 核对源码及运行边界、公开入口、镜像、数据归属和维护文档。232/232 个基线源文件有处置去向，3/3 条规定职责链完成实改，TP1、TP2 共 6/6 项阶段对照取得结果。业务 `src/` 净增 42 行，示例净增 8 行。

**改动**　验证矩阵可分别复用已发布的详细和轻量原生参考，核对镜像、部署、请求和记录方式。同批其他目标仍可在一个案例输入错误时完成评价。正式预测只读取任务、模板和成本。归档的工程约束、开发说明、窗口状态已对齐；编译产物、原生数据和本地笔记分开保留。

**验证**　两种拓扑各用 2 次结构采集、2 次轻量训练取样、1 次详细目标和 1 次轻量目标，共 12 次原生尝试。结构对照分别匹配 107、200 个动作；固定图重现实测基线且 8,601、26,440 个工作区间分别全部可比。自主预测的 TTFT / TPOT 误差分别为 TP1 的 0.21% / 4.98%、TP2 的 4.51% / 8.88%。两组同输入、同成本的基线重算只在查询墙钟开销上有差异。各 rank 的模板、工作身份及固定图成本也与旧 C++ 输出相等。[阶段证据](../../../data/architecture-acquisition-performance/r1/handoff.json) · [双 rank 编译对照](../../../data/architecture-acquisition-performance/r1/tp2-graph-baseline.json) · [轻量参考复用](../../../data/architecture-acquisition-performance/r1/matrix-reference-reuse.json)

**结论与限制**　R1 已交付。真值与训练运行相互独立，两组目标各含一个训练范围内的短请求。TP2 的 TPOT 超过最终 6% 门槛，已验证相同成本下重构前后逻辑结果一致。精度结论留给预定的模型工作和独立验收；本阶段的多 rank 采集使用两张物理卡。
