## 一、战略总目标（聚焦 SGLang + Ascend，暂不引入 CUDA / vLLM）

在单一窗口内打通**“路线二（局部按需补采泛化 + 同会话合批提速）”**与**“路线一（跨拓扑、复杂调度与真实流量的开发回归、固定图误差归因与冻结独立留出 < 6% MAPE 验收）”**的正向飞轮：

1. **清零历史结构与资格债**：根治留存 PD 对照中的 825 处端口差异（11 次 `prefill/0 run_batch`）、修复长窗口 CANN 1ns 舍入重叠、解决 TP8 留存参考 `unverified` 资格缺口与单卡分片并发模板覆盖缺口；
2. **局部按需补采跨机制/跨拓扑泛化与冷启提速**：基于上一窗口建成的零改动插拔体系（`common/components.py` + `recipes/` + `probes/` + 优先级自动回退链），将局部补采能力从“无缓存无分块的稠密 TP1”扩展至 **Prefix Cache / Chunked Prefill / Mixed Batch、多卡 TP2/TP4/TP8、PD 分离、PP 流水线与 MoE-EP**，并通过同会话多切点合批复用常驻 worker 将局部采样冷启卡时相对同点完整服务从历史 **75.5% 压至 < 50%**；
3. **8 域全维度开发回归与固定图误差归因**：系统性覆盖本机全部 3 款模型（`/models/Qwen3-8B`、`/root/models/markov-next/Mistral-7B-v0.3`、`/root/models/markov-next/Qwen3-30B-A3B`）、8 个配置域（TP1、TP1-Cache-Chunk-Mixed、TP2、TP8、PD TP1/TP2、PP3、TP2×PP3、TP4×EP4）以及真实流量/高并发压力（32 → 128 → 256 请求），用固定图实测基线与误差归因定位并消除宿主、设备与物理通信误差源；
4. **全冻结独立留出总验收（TTFT / TPOT < 6% MAPE）**：在完全隔离的独立物理拓扑留出矩阵上，达成**结构对照全匹配 + 固定图基线合格 + 自主预测闭环 TTFT 与 TPOT 各自 < 6% MAPE + 跨配置排序一致**的发布级证据包。

## 二、四道不可逾越的核心边界（防止大窗口失控）

### 边界 1：五层严格纵深边界（L0 → L4，逐层闭合，严禁跨层混改）
- **L0（底座校准与历史结构债清零）**：先清零 PD 825 端口差异、CANN 1ns 重叠与 TP8 参考资格，再进入新能力开发；
- **L1（单卡复杂调度 + 局部补采提速与调度配方扩展）**：先用 1 卡攻克冷启提速与 Chunked/Mixed/Prefix Cache，让后续 L2–L4 直接享受低卡时补采红利；
- **L2（多卡 TP2/TP4/TP8 与跨模型物理通信闭环）**：隔离攻克多卡 TP 单卡分片泛化、HCCL 物理通信分组与跨模型（Mistral-7B）验证；
- **L3（异构高级并行：PD + PP3/TP2×PP3 + MoE-EP）**：隔离攻克双池单边传输、流水线阶段交接与条件 EP 路由/变长通信；
- **L4（真实流量 Azure 2024 Trace + 高并发压力 + 模型族误差驱动演进 + 8 域总冻结留出矩阵）**：汇总全能力接受真实负载与大规模并发终极检验。
- **层间硬门控**：上一层开发回归与冻结留出核心门禁未达标前，严禁带着未收口的根因跳入下一层（确属原生框架/硬件物理限制的边缘子项须经 2 轮定位留证、单列边界结论后方可继续）。

### 边界 2：开发回归集（Dev）与冻结独立留出集（Holdout）绝对物理隔离
- 所有源码修复、局部配方开发、固定图误差归因、性能模型族演进与样本补采一律在 `data/large-scale-validation/dev/` 下完成；
- 独立留出验证全部写入 `data/large-scale-validation/holdout/`，必须使用**开发结束后冻结的源码、镜像、二进制与不可变双库发布**，并以冻结清单 SHA-256 为唯一 `--seed` 经 `prepare_matrix.py` 一次性抽出未见请求，在目标完整物理拓扑上采集独立详细参考与轻量参考；
- **反泄漏铁律**：一旦任何留出案例被用来反修代码、规则或成本模型，该案例立即永久降级为开发集，必须换新独立留出负载与新物理采集重新取证；三条验证路径的 `training` 字段必须全量通过来源隔离核验（0 例 `reference_used_for_training` 或 `training_origin_unverified`）。

### 边界 3：科学严谨性、架构品质与插件化零回退红线
- **科学/物理红线**：严守 `TS_TASK_FLIP`、双锚点 RAW、`source_clock` 的 **SymPy 有理数精确认证**（严禁浮点近似）、`NativeCase` 与 `ascend/reference` 独立性（`reference/` 0 导入 `analysis/`）、唯一逻辑动作锚点、PD/CPU 协议前提、固定图实测基线准入门槛与自主 TTFT/TPOT 统计口径；**严禁手调倍率、固定 gap、按 workload 标签拟合、拿单卡分片冒充多卡物理通信时长，或私建 mock / 独立测试工程**。
- **插件化与代码品质零回退**：新增局部采集规则、容器探针与结构检查**必须经 `common/components.py` 包贡献机制**接入 `recipes/`、`probes/`、`checks/`，严禁退回硬编码 `if/elif` 或手工互斥；严守全仓四维隔离红线（`engine/core/` 0 框架/平台字样、`sglang/` 0 `ascend`/`torch.npu`、`abi/` 外 0 `sglang.srt.`、纯 `COPY` Dockerfile），保持 **> 550 NE 业务 Python 模块 = 0、函数体内 > 25 行无空行代码墙 = 0、AST 0 环 / 0 缺失、`ruff` 0 错误、活动源码 0 `.pyc`、C++ Release 0 error / 0 warning**。
- **非目标**：不实现 CUDA/vLLM/SGLang 第二版本实机代码，不引入多机跨节点网络调度，不修改 `docs/note.md`、`.personal/`、`.clang-format`、`third_party/`、`deprecated/` 及既有历史 `data/` 资产。

### 边界 4：宽松有界预算与每阶段 Bigger-Picture Overview 纪律
- **全窗口宽松累计真机预算**（8 张 Ascend NPU，用户已明确放宽预算且自行负责磁盘清理；所有预算失败与重试不清零，严格按初始化/预热、有效观测、后处理、导出量、保留量及峰值分项记账）：
  - **总物理卡时上限：72,000 卡秒**（分摊参考：L0 ≤ 1,800 · L1 ≤ 9,000 · L2 ≤ 18,000 · L3 ≤ 21,600 · L4 ≤ 21,600 卡秒，总池可跨层按需调剂但总和严禁突破 72,000 卡秒）；
  - **总宿主后处理上限：18,000 秒**；
  - **总存储额度上限：256 GiB**（仍须如实采样并记录峰值与保留量，避免失控泄漏）。
- **每阶段强制 Bigger-Picture Overview**：每完成一个阶段，Codex 必须跳出局部 diff 重新俯瞰全仓架构、误差分布、卡时效率与剩余阶段，在 `plan.md` 追加全局审视记录并动态细化/增补后续阶段，同步更新 `status.md` 与 `log.md`。

## 三、AGY 终审硬门禁与熔断规则

终审时 AGY 将独立复算并抽检全部产物，**任一门禁不达标即打回返工**：

1. **结构零差异与历史债清零**：TP1（基础 + 复杂调度）、TP2/TP4/TP8、PD（原 825 端口差异清零）、PP3/TP2×PP3、MoE-EP 的独立物理结构验证达到 `full_structure_matched`（若个别超边界条件触发原生框架/硬件物理限制，须留存完整原生任务表证据并单列限制，绝不靠改口径放过）。
2. **局部补采泛化与冷启提速实证**：
   - 新增的 Prefix Cache / Chunked / Mixed、多卡 TP、PD、PP、MoE 局部补采配方全部经 `recipes/` + `probes/` 插件注册（核心分发器改动 = 0 行），并在 Dev/Holdout 中有真实冷/增量补采与零卡热复用日志佐证；
   - 局部采样冷启卡时相对同点完整服务实测 **< 50%**（对比历史 75.5% 给出同口径对照账本）。
3. **8 域独立冻结留出精度总表**：交付 `data/large-scale-validation/holdout/accuracy-summary.json`，逐域逐案例列出结构状态、固定图基线误差、成本替换后固定图误差、自主闭环 **TTFT MAPE、TPOT MAPE**（硬目标均 **< 6%**）、吞吐误差及跨配置排序一致性，且全部来源隔离核验通过。
4. **代码品质、文档同步与零提交快照绑定**：交付 `data/large-scale-validation/source-manifest.json`（工作区 `src/` 逐文件 SHA-256）与 `evidence-manifest.json`（全部关键证据 SHA-256），确认全仓品质红线零回退、`README.md` 与静态设计文档同步更新、全流程零 `git commit`/`git push`。
5. **失败熔断**：同一根因连续尝试 2 轮无新进展，或单层遇到无法绕过的原生框架/硬件物理限制，或累计真机预算触顶时，立即止损留证记入 `log.md` / `status.md` 交回 AGY 裁决，严禁静默扩预算、降标或手调系数。
